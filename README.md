# MC CTRL

> Modern Minecraft Server Control Panel built with Python.

MC CTRL is a futuristic Minecraft server launcher and management dashboard focused on simplicity, customization, performance monitoring, remote access, and modern UI design.

# Installation

## Option 1 — Windows Installer

Run:

```text
install_requirements.bat
```

This installer:

- Checks Python
- Installs dependencies
- Verifies modules
- Shows animated loading UI
- Helps beginners set everything up

---

## Option 2 — Cross Platform Python Installer

Run:

```bash
python install_requirements.py
```

or:

```bash
python3 install_requirements.py
```

Features:

- Cross-platform
- Animated Braille loading spinner
- Progress bars
- Professional terminal UI
- Better dependency handling

---

# Python Dependencies

MC CTRL uses:

```bash
pip install customtkinter psutil matplotlib tkinterdnd2 pillow
```

Linux users may also need:

```bash
sudo apt install python3-tk
```

macOS users may need:

```bash
brew install python-tk
```

# Troubleshooting

## Python not found

Install Python and enable:

```text
Add Python to PATH
```

---

## Java not found

Install Java 21 and configure the Java path.

---

## App does not start

Install dependencies manually:

```bash
pip install customtkinter psutil matplotlib tkinterdnd2 pillow
```

---

## Server will not launch

Check:

- `server.jar` exists
- Java path is correct
- Enough RAM is available
- Firewall permissions
